# Install edgeglint

1. Read the selected checkout's [AGENTS.md](https://github.com/dataxad/edgeglint/blob/main/AGENTS.md).
2. Read its [README.md](https://github.com/dataxad/edgeglint/blob/main/README.md) for use terms and installation alternatives.
3. Examine the host's framework, Wrangler configuration and public route list.
4. Follow AGENTS.md and the applicable [recipe](https://github.com/dataxad/edgeglint/blob/main/docs/install.md).
5. Run the installation checks in AGENTS.md.
6. Report the source commit, deployed checks and unverified steps.

Use the files at the selected commit. The URLs above show current `main`.
AGENTS.md is the shared procedure; do not keep a different installation checklist here.

The package is not on npm. A dependency install does not activate this skill.
